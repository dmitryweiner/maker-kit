# 3d — meshes, checks, STL, the 3D view

`mesh`, `validate` and `stl` know nothing of three: a worker imports them
freely. Only `viewer` imports three (a peer dependency of the kit).
Millimetres, z up (the printing convention), triangles counter-clockwise
seen from outside.

## 3d/mesh

```ts
interface SurfaceMesh { positions: Float32Array; normals: Float32Array; indices: Uint32Array }
interface IndexedMesh { positions: Float32Array; indices: Uint32Array }
meshNormals(positions, indices);   // area-weighted vertex normals
isValidMesh(mesh);                 // whole triangles, indices in range, finite: for meshes from outside
boxMesh(width, depth, height);     // a box on the bed, centred: a stand-in, a test solid
```

## 3d/validate — the export gate

```ts
const report = validateMesh(mesh);   // finite, indices, watertight, volume, degenerate, extents
const { blockers, warnings } = assessExport(report, true);   // Message<'kit.mesh.*'>[]
signedVolume(positions, indices);
```

Blocks: non-finite, broken indices, empty, flat, open and inside-out (when
it should be closed), more than 1 % degenerate triangles. Warns of more
than 8 slivers below that (a boolean's noise). An app's own limits (Case
Constructor's largest part) are its own checks.

## 3d/stl

```ts
encodeSTL(mesh, { brand: 'Plate Builder', name: 'Door sign' });   // binary, mm; the header names the app and the part
parseSTL(buffer);       // binary or ASCII, welded, collapsed triangles dropped; throws on what is not STL
weld(soup);             // 9 floats a triangle → an indexed mesh
stlFileName('Door sign', 'plate');   // 'door-sign.stl'
```

## 3d/viewer

```ts
const viewer = createViewer(canvas);   // null without WebGL: the app goes on without its view
viewer?.setMeshes([{ mesh }, { mesh: lid, material: ghost }]);
viewer?.camera('iso' | 'top' | 'front' | 'side' | 'bottom');
viewer?.fitBed(220, 220);      // the grid is at least the printer's bed
viewer?.setInset(px);          // ui/sheet's onInset: fit what the sheet leaves free
viewer?.recolor();             // after a theme or an accent change
viewer?.model.add(captions);   // the app's own objects, z-up, moving with the model
```

- The model stands on the bed, centred; the grid (1 cm cells, 5 cm on a
  big model) is a little wider and shows from above only.
- The camera fits the model's bounding sphere once, and again when its size
  changes by a fifth, keeping its direction; a resize refits until the
  person turns or zooms.
- Frames on demand: a camera move (with damping), a resize, new meshes.
- Light from one side, low: a 0.2 mm relief shades readably. Creased
  normals at 40°: a slab's edges stay sharp.
- Colours from the page's tokens: `--bg` for the background, `--line` and
  `--muted` for the grid.
